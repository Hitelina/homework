# Описание проекта

Этот проект содержит набор Python-функций для маскирования номеров банковских карт и счетов, а также для фильтрации и сортировки данных о транзакциях по статусу и дате.

## Описание функций

В папке src лежат файлы с функциями:
  1. get_mask_card_number - Функция которая принимает на вход номер карты и возвращает ее маску"
  2. get_mask_account - Маскирует номер счета, показывая только последние 4 цифры.
  3. mask_account_card - Обрабатывает строку с типом и номером, возвращает строку с типом и маскированным номером
  4. get_date - Принимает строку с датой в формате ISO 8601 и возвращает строку в формате ДД.ММ.ГГГГ.
  5. filter_by_state - Фильтрует список словарей по значению ключа 'state'
  6. sort_by_date - Сортирует список словарей по дате (ключ 'date') 

## Установка
Для установки и запуска проекта необходимо:

1. Установить Python 3.7 или выше.
2. Установить Poetry (менеджер зависимостей):
   ```
   pip install poetry
   
   ```
3. Клонировать репозиторий проекта: 
   ```
   git clone git@github.com:Hitelina/homework.git
      
   ```
4. Установить зависимости проекта:
   ```
   poetry install
   
   ```
Все зависимости управляются с помощью Poetry и указаны в файле pyproject.toml.
